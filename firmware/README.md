## 3、After entering the file selection and address configuration interface, perform the corresponding configurations.
<img width="1107" height="1303" alt="image" src="https://github.com/user-attachments/assets/b2af8b36-213a-49dd-b98f-a1fe130c103d" />

(1) Select the programming file

(2) Fill in the programming address

(3) Check the checkbox

(4) Configure SPI (only once, it will remain unchanged afterwards)

(5) Select the programming port and baud rate (if programming fails or the port is not detected, please hold down the boot key and then plug in the data cable, release it after selecting the port)

(6) Start programming

> [!NOTE]
> * Generally, the files we provide are merged files, so the burning address is 0x0. If they are generated by your own compilation, there are usually three files: Bootloader.bin -> 0x0, partition.bin -> 0x8000, firmware.bin -> 0x10000. The last file is your own project name, and its address may be another address, so please set it according to the compilation result.
